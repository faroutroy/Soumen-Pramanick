💾 Create SearchService.ts

This is the core logic that handles all SharePoint API interactions. Create src/webparts/multiListSearch/services/SearchService.ts:

SearchService.ts (Part 1 of 2) 
import { sp } from "@pnp/sp/presets/all";
import { ISearchResult, IListInfo, ISearchResponse } from "../models/ISearchResult";

export class SearchService {
  
  // Initialize PnP JS with SharePoint context
  public async initialize(siteUrl: string): Promise<void> {
    sp.setup({
      sp: {
        baseUrl: siteUrl
      }
    });
  }

  // Get all non-hidden lists from the site
  public async getAllLists(): Promise<IListInfo[]> {
    try {
      const lists = await sp.web.lists
        .filter("Hidden eq false and BaseTemplate eq 100")
        .select("Id", "Title", "ItemCount")
        .get();

      return lists.map(list => ({
        id: list.Id,
        title: list.Title,
        itemCount: list.ItemCount
      }));
    } catch (error) {
      console.error("Error fetching lists:", error);
      throw error;
    }
  }
SearchService.ts (Part 2 of 2) 
  // Main search function - searches all lists in parallel
  public async searchAllLists(
    searchTerm: string, 
    targetLists?: string[]
  ): Promise<ISearchResponse> {
    const startTime = performance.now();
    
    try {
      // Get all lists or filter by target lists
      let lists = await this.getAllLists();
      
      if (targetLists && targetLists.length > 0) {
        lists = lists.filter(l => 
          targetLists.some(t => 
            l.title.toLowerCase() === t.toLowerCase()
          )
        );
      }

      // Search each list in parallel for maximum performance
      const searchPromises = lists.map(list => 
        this.searchList(list.id, list.title, searchTerm)
      );

      const resultsArrays = await Promise.all(searchPromises);
      
      // Flatten and combine results from all lists
      const allResults = resultsArrays.flat();
      
      // Sort by relevance
      const sortedResults = this.sortResults(allResults, searchTerm);

      const executionTime = performance.now() - startTime;

      return {
        results: sortedResults,
        totalCount: sortedResults.length,
        searchTerm,
        executionTime
      };
    } catch (error) {
      console.error("Error during search:", error);
      throw error;
    }
  }

  // Search a single list
  private async searchList(
    listId: string, 
    listTitle: string, 
    searchTerm: string
  ): Promise<ISearchResult[]> {
    try {
      const filter = this.buildFilterQuery(searchTerm);
      
      const items = await sp.web.lists.getById(listId).items
        .select("Id", "Title", "Modified", "Author/Title")
        .expand("Author")
        .filter(filter)
        .top(100)
        .get();

      return items.map(item => ({
        id: item.Id,
        title: item.Title,
        listTitle: listTitle,
        listId: listId,
        modified: new Date(item.Modified),
        author: item.Author?.Title || "Unknown",
        url: `\${sp.web.url}/Lists/\${listTitle}/DispForm.aspx?ID=\${item.Id}`
      }));
    } catch (error) {
      console.warn(`Error searching list \${listTitle}:`, error);
      return [];
    }
  }

  // Build OData filter query
  private buildFilterQuery(searchTerm: string): string {
    const term = searchTerm.toLowerCase();
    return `(substringof('\${term}', tolower(Title)))`;
  }

  // Sort results by relevance
  private sortResults(
    results: ISearchResult[], 
    searchTerm: string
  ): ISearchResult[] {
    return results.sort((a, b) => {
      const aTitleMatch = a.title.toLowerCase()
        .includes(searchTerm.toLowerCase());
      const bTitleMatch = b.title.toLowerCase()
        .includes(searchTerm.toLowerCase());

      if (aTitleMatch && !bTitleMatch) return -1;
      if (!aTitleMatch && bTitleMatch) return 1;

      return b.modified.getTime() - a.modified.getTime();
    });
  }
}
🚀 Performance Optimization

The service uses Promise.all() to query all lists in parallel, dramatically reducing total execution time compared to sequential queries.

MultiListSearch.tsx (Part 1 of 3) 
import * as React from 'react';
import { ISearchResult } from '../models/ISearchResult';
import { SearchService } from '../services/SearchService';
import styles from './MultiListSearch.module.scss';

export interface IMultiListSearchProps {
  siteUrl: string;
}

export interface IMultiListSearchState {
  searchTerm: string;
  results: ISearchResult[];
  isLoading: boolean;
  error?: string;
  totalCount: number;
}

export default class MultiListSearch extends 
  React.Component<IMultiListSearchProps, IMultiListSearchState> {
  
  private searchService: SearchService;
  private searchTimeout: NodeJS.Timeout;

  constructor(props: IMultiListSearchProps) {
    super(props);
    
    this.state = {
      searchTerm: '',
      results: [],
      isLoading: false,
      totalCount: 0
    };

    this.searchService = new SearchService();
  }

  public async componentDidMount(): Promise<void> {
    await this.searchService.initialize(this.props.siteUrl);
  }
MultiListSearch.tsx (Part 2 of 3) 
  private handleSearchChange = (
    event: React.ChangeEvent<HTMLInputElement>
  ): void => {
    const searchTerm = event.target.value;
    this.setState({ searchTerm });

    // Debounce search to avoid excessive API calls
    clearTimeout(this.searchTimeout);
    
    if (searchTerm.length >= 3) {
      this.searchTimeout = setTimeout(() => {
        this.executeSearch(searchTerm);
      }, 500);
    } else {
      this.setState({ results: [], totalCount: 0 });
    }
  }

  private async executeSearch(searchTerm: string): Promise<void> {
    this.setState({ isLoading: true, error: undefined });

    try {
      const response = await this.searchService
        .searchAllLists(searchTerm);
      
      this.setState({
        results: response.results,
        totalCount: response.totalCount,
        isLoading: false
      });
    } catch (error) {
      this.setState({
        error: 'Failed to search lists. Please try again.',
        isLoading: false
      });
    }
  }
MultiListSearch.tsx (Part 3 of 3) 
  public render(): React.ReactElement<IMultiListSearchProps> {
    const { searchTerm, results, isLoading, error, totalCount } = this.state;

    return (
      <div className={styles.multiListSearch}>
        <div className={styles.searchBox}>
          <input
            type="text"
            placeholder="Search across all lists..."
            value={searchTerm}
            onChange={this.handleSearchChange}
            className={styles.searchInput}
          />
        </div>

        {isLoading && (
          <div className={styles.loading}>
            Searching...
          </div>
        )}

        {error && (
          <div className={styles.error}>{error}</div>
        )}

        {!isLoading && results.length > 0 && (
          <div className={styles.results}>
            <div className={styles.resultCount}>
              Found {totalCount} results
            </div>
            {results.map(result => (
              <div key={`\${result.listId}-\${result.id}`} 
                   className={styles.resultItem}>
                <a href={result.url} className={styles.resultTitle}>
                  {result.title}
                </a>
                <div className={styles.resultMeta}>
                  <span className={styles.listName}>
                    {result.listTitle}
                  </span>
                  <span className={styles.modified}>
                    Modified: {result.modified.toLocaleDateString()}
                  </span>
                  <span className={styles.author}>
                    By: {result.author}
                  </span>
                </div>
              </div>
            ))}
          </div>
        )}

        {!isLoading && searchTerm.length >= 3 && results.length === 0 && (
          <div className={styles.noResults}>
            No results found for "{searchTerm}"
          </div>
        )}
      </div>
    );
  }
}

Test Your Solution

🚀 Start Local Development Server

In your terminal, run:

Terminal Command 
gulp serve

This will:

  • Build your project
  • Start a local development server
  • Open the SharePoint Workbench in your browser

🌐 Test in SharePoint Workbench

Navigate to your SharePoint site's workbench:

URL Format:

https://yourtenant.sharepoint.com/sites/yoursite/_layouts/15/workbench.aspx
  1. Click the "+" icon to add a web part
  2. Find "MultiListSearch" in the web part picker
  3. Add it to the page
  4. Try searching for items in your lists!

✅ Validation Checklist

  • Search input accepts text
  • Debouncing works (wait 500ms after typing)
  • Loading indicator appears during search
  • Results appear from multiple lists
  • Each result shows: title, list name, modified date, author
  • Clicking a result navigates to the item
  • No results message appears for non-matching searches
  • Error handling works (try disconnecting internet)
🎊 Testing Complete!

If all checks pass, your POC is working correctly! The search should return results in under 3 seconds for typical datasets.

🔍 Troubleshooting
  • CORS Error: Make sure you're using the SharePoint hosted workbench, not localhost
  • No Results: Verify your site has lists with items containing matching text
  • Build Error: Run npm install again to ensure all packages are installed

Deploy to SharePoint

📦 Build Production Package

Stop the local server (Ctrl+C) and run these commands:

Terminal Commands 
# Create production bundle
gulp bundle --ship

# Package the solution
gulp package-solution --ship

This creates a .sppkg file in sharepoint/solution/

☁️ Upload to App Catalog

  1. Open SharePoint Admin Center
  2. Navigate to: More features → Apps → App Catalog
  3. Click Apps for SharePoint
  4. Click Upload and select your .sppkg file
  5. Check "Make this solution available to all sites"
  6. Click Deploy

➕ Add to Your Site

  1. Navigate to your target SharePoint site
  2. Go to Site Contents
  3. Click New → App
  4. Find "multi-list-search-client-side-solution"
  5. Click Add
  6. Wait for installation to complete (~30 seconds)

🎯 Add Web Part to Page

  1. Edit any SharePoint page
  2. Click + to add a section
  3. Search for "MultiListSearch"
  4. Click to add it to the page
  5. Click Publish
🎉 Deployment Complete!

Your SharePoint Multi-List Search is now live and available to all users! The solution is production-ready and can search across all lists in the site.
